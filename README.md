# Just Chill Website
Desktop-first responsive landing page for the Just Chill cooling-jacket project.

Files:
- index.html
- style.css
- script.js
- assets/just-chill-visual.png

Deploy:
1. Upload all files/folders to a GitHub repository.
2. Enable GitHub Pages, or import the repository into Vercel.
3. Keep the assets folder in the same location as index.html.
